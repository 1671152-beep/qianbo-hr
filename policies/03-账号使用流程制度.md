# 账号使用流程制度

## 1. 目的

规范公司各类账号（直播平台账号、社交媒体账号、企业系统账号等）的申请、使用、管理和注销流程，保障公司数字资产安全，明确权责归属。

## 2. 适用范围

适用于公司所有业务账号，包括：
- 直播平台账号（抖音、快手、视频号、小红书等）
- 社交媒体账号（微博、公众号、B站等）
- 广告投放账号（巨量引擎、磁力引擎等）
- 企业办公账号（OA、邮箱、协作工具等）
- 第三方服务账号（设计工具、数据分析工具等）

## 3. 账号分类管理

### 3.1 按重要性分级
| 级别 | 定义 | 示例 | 管理要求 |
|------|------|------|----------|
| A级 | 核心资产 | 主直播账号、主品牌号 | 总经理直管，双人授权 |
| B级 | 重要资产 | 分账号、投放账号 | 中心总监管理，定期汇报 |
| C级 | 一般资产 | 测试号、个人工作号 | 部门负责人管理 |

### 3.2 按归属分类
| 类型 | 说明 | 权属 |
|------|------|------|
| 公司号 | 公司注册，公司运营 | 公司所有 |
| 合作号 | 与达人/主播合作账号 | 按协议约定 |
| 个人号 | 员工个人账号用于工作 | 需签署使用协议 |

## 4. 账号申请流程

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  提交账号  │ → │  评估审核  │ → │  注册/获取  │ → │  信息备案  │ → │  权限分配  │
│  申请表   │    │          │    │   账号    │    │          │    │          │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
```

### 4.1 申请条件
- 明确账号用途和业务目标
- 符合公司战略方向
- 在预算范围内（账号费用需提前申请）
- 指定账号负责人

### 4.2 申请材料
- 《账号申请表》
- 账号用途说明
- 预期投入产出分析（A级账号）
- 费用预算（如有）
- 运营计划书（A级账号）

### 4.3 审批权限
| 账号级别 | 中心总监 | 副总经理 | 总经理 |
|----------|----------|----------|--------|
| A级 | 审核 | 审核 | 审批 |
| B级 | 审批 | - | - |
| C级 | 审批 | - | - |

## 5. 账号使用规范

### 5.1 基本守则
- 账号仅限工作用途，禁止私用
- 不得发布违法违规、违反公序良俗内容
- 不得泄露公司商业机密和敏感信息
- 不得擅自修改账号关键信息（名称、绑定手机等）

### 5.2 密码管理
- 初始密码必须由系统生成强密码
- 首次登录后必须修改密码
- 密码长度≥12位，包含大小写+数字+符号
- 每90天强制更换密码
- 禁止多账号共用同一密码
- 禁止将密码告知无关人员

### 5.3 绑定信息管理
| 信息类型 | 管理要求 |
|----------|----------|
| 手机号 | 优先使用公司分配号码 |
| 邮箱 | 必须使用公司邮箱 |
| 实名认证 | 按业务需要，优先公司主体 |
| 银行卡 | 必须绑定公司账户 |

## 6. 账号费用管理

### 6.1 费用类型
| 类型 | 说明 | 预算归属 |
|------|------|----------|
| 账号服务费 | 平台认证、年费等 | 账号费用科目 |
| 投流费用 | 广告投放、DOU+等 | 投流费用科目 |
| 内容制作费 | 视频、直播制作 | 视频/音频费用科目 |
| 软件工具费 | 剪辑、数据工具 | 软件服务费科目 |

### 6.2 预算标准（月度）
| 中心 | 账号费用 | 投流费用 | 视频费用 | 音频费用 |
|------|----------|----------|----------|----------|
| 基地管理中心 | ¥9,000 | ¥40,000 | ¥3,000 | ¥18,000 |
| 本地生活运营中心 | ¥16,500 | ¥50,000 | ¥2,500 | ¥3,600 |

### 6.3 费用申请
- 账号服务费：按年/季度申请
- 投流费用：按月申请，需附投流计划
- 单笔超过5000元需事前申请

## 7. 账号运营管理

### 7.1 内容发布规范
- 发布前需经内容审核
- 涉及公司品牌、产品需合规审查
- 直播内容需提前报备（A级账号）
- 评论区需及时监控和回复

### 7.2 数据监控
- 每日查看账号数据（粉丝、播放、转化）
- 异常情况立即上报
- 周报汇总账号运营数据
- 月度进行账号价值评估

### 7.3 账号安全
- 开启登录保护、异地登录提醒
- 定期检查账号授权应用
- 发现异常立即修改密码并上报
- 定期备份重要数据

## 8. 账号交接与注销

### 8.1 账号交接
- 负责人变更需办理交接手续
- 交接内容：账号密码、绑定信息、运营数据、未结事项
- 交接完成后修改密码
- 填写《账号交接单》

### 8.2 员工离职处理
| 账号类型 | 处理方式 |
|----------|----------|
| 公司号 | 更换密码，转移至接替人 |
| 合作号 | 按合作协议处理 |
| 个人号 | 解除公司绑定，签署离职声明 |

### 8.3 账号注销
- 长期不用的账号及时注销
- 注销前备份重要数据
- 清理账号内资金
- 填写《账号注销单》

## 9. 违规处理

| 违规行为 | 处理措施 |
|----------|----------|
| 私自注册公司账号 | 收回账号，警告处分 |
| 泄露账号密码 | 立即修改密码，视情节处分 |
| 发布违规内容 | 删除内容，追究责任，严重者辞退 |
| 私用公司账号获利 | 追回所得，辞退并追究法律责任 |
| 擅自修改绑定信息 | 恢复原状，警告处分 |

## 10. 附则

- 本制度由人事行政财务中心制定并解释
- 各中心可根据业务特点制定实施细则
- 自发布之日起执行
