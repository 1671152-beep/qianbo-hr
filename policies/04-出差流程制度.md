# 出差流程制度

## 1. 目的

规范员工因公出差的申请、审批、报销等流程，明确出差标准，控制差旅成本，保障员工出差期间的权益与安全。

## 2. 适用范围

适用于公司全体员工因公务需要离开常驻地（以公司注册地或主要办公地为准）的工作活动。

## 3. 出差分类

### 3.1 按地域分类
| 类型 | 定义 | 审批要求 |
|------|------|----------|
| 本地出差 | 当日往返，市内及周边 | 部门负责人审批 |
| 短途出差 | 1-2天，省内 | 中心总监审批 |
| 长途出差 | 3天以上或跨省 | 副总经理审批 |
| 国际出差 | 出境 | 总经理审批 |

### 3.2 按目的分类
- 商务洽谈（客户拜访、合作谈判）
- 项目执行（拍摄、活动、落地执行）
- 培训学习（外部培训、行业会议）
- 考察调研（市场调研、供应商考察）

## 4. 出差标准

### 4.1 交通工具
| 职级 | 飞机 | 火车 | 市内交通 |
|------|------|------|----------|
| 总经理/副总经理 | 商务舱 | 一等座 | 实报实销/专车 |
| 中心总监 | 经济舱 | 一等座 | 实报实销/打车 |
| 部门经理及以下 | 经济舱（限4h以上） | 二等座 | 实报实销/打车 |

**备注**：
- 机票提前预订，优先选择折扣舱位
- 火车行程4小时内优先选择高铁/动车
- 超标需事前申请，否则超标部分自理

### 4.2 住宿标准
| 城市级别 | 总经理/副总经理 | 中心总监 | 部门经理及以下 |
|----------|-----------------|----------|----------------|
| 一线城市 | ≤800元/晚 | ≤500元/晚 | ≤400元/晚 |
| 二线城市 | ≤600元/晚 | ≤400元/晚 | ≤300元/晚 |
| 三线及以下 | ≤500元/晚 | ≤350元/晚 | ≤250元/晚 |

**备注**：
- 同性两人出差应合住标准间，按单人标准报销
- 特殊情况需单独住宿需事前说明
- 优先选择协议酒店，无协议酒店选择连锁酒店

### 4.3 餐饮补贴
| 职级 | 一线城市 | 其他城市 |
|------|----------|----------|
| 全体 | 150元/天 | 120元/天 |

**备注**：
- 按自然日计算，出发日按半天计
- 由公司统一安排餐饮的不发补贴
- 无需发票，直接按天数计算

### 4.4 其他补贴
| 项目 | 标准 | 说明 |
|------|------|------|
| 通讯补贴 | 30元/天 | 出差期间通讯费 |
| 行李超重 | 实报实销 | 因工作需要的超重费用 |
| 签证费用 | 实报实销 | 因公出境签证 |
| 保险费用 | 实报实销 | 出差意外险 |

## 5. 出差申请流程

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  填写出差  │ → │  行程确认  │ → │  审批流程  │ → │  出差准备  │ → │  执行出差  │
│  申请表   │    │          │    │          │    │          │    │          │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
```

### 5.1 申请时间
- 一般出差：提前3天申请
- 长途出差：提前7天申请
- 国际出差：提前15天申请
- 紧急出差：可口头申请后24小时内补单

### 5.2 申请内容
- 出差人员及职级
- 出差时间（出发/返回日期）
- 出差地点
- 出差目的
- 预计费用预算
- 交通工具需求
- 住宿需求

### 5.3 审批权限
| 出差类型 | 部门负责人 | 中心总监 | 副总经理 | 总经理 |
|----------|------------|----------|----------|--------|
| 本地出差 | 审批 | - | - | - |
| 短途出差 | 审核 | 审批 | - | - |
| 长途出差 | 审核 | 审核 | 审批 | - |
| 国际出差 | 审核 | 审核 | 审核 | 审批 |

### 5.4 出差准备
- 审批通过后由行政协助预订机酒
- 领取出差所需资料和设备
- 确认工作交接事项
- 购买出差意外险

## 6. 出差期间管理

### 6.1 工作要求
- 保持通讯畅通
- 每日汇报工作进展
- 重要事项及时请示
- 维护公司形象

### 6.2 费用控制
- 严格按标准执行
- 超支需事前申请追加
- 保留所有票据原件
- 每日记录费用支出

### 6.3 安全管理
- 遵守当地法律法规
- 注意人身财产安全
- 购买足额保险
- 遇紧急情况立即联系公司和报警

## 7. 出差报销

### 7.1 报销时限
- 出差结束后3个工作日内提交报销
- 特殊情况不超过7个工作日

### 7.2 报销材料
- 出差审批单
- 差旅费报销明细表
- 交通费票据（机票、火车票、打车票）
- 住宿费发票
- 其他费用票据
- 出差总结报告（3天以上需提供）

### 7.3 报销标准
| 费用类型 | 报销方式 | 说明 |
|----------|----------|------|
| 交通费 | 实报实销 | 凭票据，按标准 |
| 住宿费 | 实报实销 | 凭发票，按标准 |
| 餐饮补贴 | 定额补贴 | 无需票据 |
| 市内交通 | 实报实销 | 凭票据 |

## 8. 出差总结

### 8.1 总结要求
- 3天以上出差需提交书面总结
- 总结内容包括：
  - 出差目的完成情况
  - 主要成果和收获
  - 费用执行情况
  - 后续跟进事项

### 8.2 成果归档
- 客户名片/联系方式录入CRM
- 合同/协议等文件归档
- 照片/视频素材上传服务器
- 经验教训总结分享

## 9. 特殊情况处理

### 9.1 出差延期
- 提前申请，说明原因
- 获得批准后方可延期
- 超期费用需单独申请

### 9.2 出差取消
- 及时通知相关人员
- 取消机酒预订
- 已产生费用按实际情况处理

### 9.3 私人行程
- 不得影响工作
- 私人行程费用自理
- 延长天数需按请假处理

## 10. 违规处理

| 违规行为 | 处理措施 |
|----------|----------|
| 未经审批出差 | 费用不予报销 |
| 虚报出差天数 | 追回虚报款项，警告处分 |
| 超标不报批 | 超标部分自理 |
| 虚假出差 | 严肃处理，直至辞退 |
| 出差期间违纪 | 按公司纪律处分 |

## 11. 附则

- 本制度由人事行政财务中心制定并解释
- 各中心可根据业务需要制定补充规定
- 自发布之日起执行
