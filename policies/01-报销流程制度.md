# 报销流程制度

## 1. 目的

规范公司费用报销流程，明确报销标准与审批权限，提高财务管理效率，确保公司资金安全。

## 2. 适用范围

适用于公司全体员工因公务产生的各项费用报销。

## 3. 报销分类与标准

### 3.1 差旅费用
| 项目 | 标准 | 说明 |
|------|------|------|
| 交通费 | 实报实销 | 凭票据报销，优先选择经济舱/二等座 |
| 住宿费 | ≤300元/晚 | 一线城市≤400元，凭发票报销 |
| 餐饮补贴 | 100元/天 | 无需发票，按出差天数计算 |
| 市内交通 | 50元/天 | 无需发票，包干使用 |

### 3.2 办公费用
| 项目 | 标准 | 审批要求 |
|------|------|----------|
| 办公用品 | ≤200元/次 | 部门负责人审批 |
| 快递费 | 实报实销 | 需注明事由 |
| 通讯费 | 100元/月 | 提供话费账单 |
| 网络费 | 实报实销 | 仅限工作场所 |

### 3.3 业务招待费
| 招待对象 | 人均标准 | 审批要求 |
|----------|----------|----------|
| 普通客户 | ≤200元/人 | 中心总监审批 |
| 重要客户 | ≤500元/人 | 副总经理审批 |
| 政府/合作方 | ≤800元/人 | 总经理审批 |

### 3.4 培训学习费
- 内部培训：凭发票实报实销
- 外部培训：需提前申请，审批后报销
- 考试认证：与公司业务相关可报销

## 4. 报销流程

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  整理票据  │ → │  填写申请  │ → │  直属上级  │ → │  财务审核  │ → │  打款到账  │
│  & 凭证   │    │  单提交   │    │   审批    │    │   & 复核   │    │          │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
```

### 4.1 详细步骤

**第一步：整理票据**
- 收集所有原始发票/收据
- 发票抬头：千播（或公司全称）
- 发票内容与实际用途一致
- 电子发票需打印并注明"重复报销责任自负"

**第二步：填写报销单**
- 登录HR系统 → 费用报销模块
- 选择报销类型（差旅/办公/招待/其他）
- 填写报销明细，上传票据照片
- 关联相关审批单（如有事前申请）

**第三步：直属上级审批**
- 核实费用真实性、合理性
- 确认费用在预算范围内
- 48小时内完成审批

**第四步：财务审核**
- 审核票据合规性
- 核对金额准确性
- 检查审批流程完整性

**第五步：打款到账**
- 审核通过后3个工作日内打款
- 默认打入工资卡
- 系统推送到账通知

## 5. 审批权限矩阵

| 报销金额 | 直属上级 | 中心总监 | 副总经理 | 总经理 |
|----------|----------|----------|----------|--------|
| ≤1000元 | 审批 | - | - | - |
| 1001-5000元 | 审核 | 审批 | - | - |
| 5001-20000元 | 审核 | 审核 | 审批 | - |
| >20000元 | 审核 | 审核 | 审核 | 审批 |

## 6. 报销时限

- **一般费用**：发生后30天内报销
- **差旅费用**：出差结束后7天内报销
- **特殊情况**：超期需书面说明原因

## 7. 不予报销情形

- 超过报销标准部分（未经特批）
- 发票不合规（虚假、过期、信息错误）
- 与工作无关的个人消费
- 未按流程事前申请的大额支出
- 超过报销时限且无正当理由

## 8. 附件要求

- 增值税普通/专用发票
- 电子发票打印件
- 支付凭证截图
- 出差审批单（差旅费）
- 费用申请单（事前申请的费用）
- 招待事由说明（招待费）

## 9. 违规处理

| 违规行为 | 处理措施 |
|----------|----------|
| 虚假报销 | 追回款项，警告处分，情节严重者辞退 |
| 超标准报销 | 超标部分自理，予以警告 |
| 重复报销 | 追回款项，记入诚信档案 |
| 超期未报 | 财务有权拒绝受理 |

## 10. 附则

- 本制度由人事行政财务中心制定并解释
- 自发布之日起执行
- 每半年评估修订一次
