# 培训管理流程制度

## 1. 目的

建立系统的培训体系，提升员工能力素质，促进员工职业发展，支持公司业务增长。

## 2. 适用范围

适用于公司全体员工的培训管理。

## 3. 培训类型

### 3.1 新员工培训
- 公司概况与文化
- 规章制度
- 岗位技能培训
- 导师带教

### 3.2 专业技能培训
- 岗位专业知识
- 行业前沿趋势
- 工具使用技能

### 3.3 管理能力培训
- 领导力
- 团队管理
- 项目管理

### 3.4 通用能力培训
- 沟通表达
- 时间管理
- 办公软件

## 4. 培训流程

```
需求调研 → 培训计划 → 方案设计 → 组织实施 → 效果评估 → 成果转化
```

### 4.1 需求调研
- 年度培训需求调查
- 绩效改进分析
- 业务需求分析

### 4.2 培训计划
- 年度培训计划
- 月度培训安排
- 临时培训申请

### 4.3 培训方式
| 方式 | 说明 |
|------|------|
| 内部培训 | 公司内部讲师授课 |
| 外部培训 | 参加外部机构培训 |
| 线上学习 | 在线课程学习 |
| 外派学习 | 脱产学习深造 |
| 导师制 | 一对一指导 |

### 4.4 费用管理
- 内部培训：公司承担
- 外部培训：按年度预算执行
- 个人发展培训：可申请补贴

## 5. 培训协议

外部培训费用≥5000元需签署《培训协议》：
- 服务期约定（通常为1-3年）
- 未满服务期离职需按比例赔偿

## 6. 附则

- 本制度由人事行政财务中心制定并解释
- 自发布之日起执行
