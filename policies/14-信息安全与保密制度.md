# 信息安全与保密制度

## 1. 目的

保护公司商业秘密和敏感信息，防范信息安全风险，维护公司合法权益。

## 2. 适用范围

适用于公司全体员工及外包人员。

## 3. 保密信息范围

| 类别 | 内容 |
|------|------|
| 商业秘密 | 经营策略、客户信息、供应商信息、财务数据 |
| 技术秘密 | 算法、数据、系统架构、源代码 |
| 账号信息 | 各类平台账号、密码 |
| 人员信息 | 员工档案、薪酬信息 |
| 合同信息 | 合作协议、价格条款 |

## 4. 保密义务

### 4.1 基本要求
- 严格保守公司秘密
- 未经授权不得对外披露
- 不得用于个人目的
- 离职后继续承担保密义务

### 4.2 日常规范
- 敏感文件加密存储
- 重要文件不随意打印
- 离职时归还/删除所有资料
- 不随意连接不明网络

## 5. 信息安全

### 5.1 账号安全
- 密码定期更换
- 不共享账号密码
- 离职立即注销账号

### 5.2 设备安全
- 安装正版杀毒软件
- 不随意插拔不明U盘
- 设备丢失立即上报

### 5.3 网络安全
- 不随意点击不明链接
- 不下载不明附件
- 敏感操作使用公司网络

## 6. 泄密处理

| 情形 | 处理 |
|------|------|
| 过失泄密 | 警告，造成损失的赔偿 |
| 故意泄密 | 辞退，追究法律责任 |
| 离职后泄密 | 追究法律责任 |

## 7. 竞业限制

核心人员离职后需遵守竞业限制：
- 限制期：6-24个月
- 限制范围：同行业竞争企业
- 补偿：离职后按月支付

## 8. 附则

- 本制度由人事行政财务中心制定并解释
- 入职需签署《保密协议》
- 自发布之日起执行
