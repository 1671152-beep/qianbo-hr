# 离职交接流程制度

## 1. 目的

规范员工离职流程，确保工作顺利交接，保护公司利益，维护离职员工合法权益。

## 2. 适用范围

适用于公司全体员工的离职管理。

## 3. 离职类型

| 类型 | 说明 |
|------|------|
| 辞职 | 员工主动提出离职 |
| 协商解除 | 双方协商一致解除 |
| 辞退 | 公司主动解除（过失/非过失） |
| 合同到期 | 劳动合同到期不续签 |
| 退休 | 达到法定退休年龄 |

## 4. 离职流程

### 4.1 辞职流程
```
提交辞职申请 → 上级沟通 → 审批 → 工作交接 → 离职面谈 → 手续办理 → 离职
```

**提前通知期**：
- 试用期：提前3天
- 正式员工：提前30天

### 4.2 审批权限
| 岗位 | 审批人 |
|------|--------|
| 普通员工 | 中心总监 |
| 经理级 | 副总经理 |
| 总监级 | 总经理 |

### 4.3 工作交接
| 交接事项 | 内容 |
|----------|------|
| 工作资料 | 文件、数据、账号密码 |
| 客户资源 | 客户信息、合作进展 |
| 项目进度 | 当前项目状态和待办 |
| 公司资产 | 设备、办公用品归还 |
| 财务事项 | 借款、报销清理 |

### 4.4 离职面谈
- 了解离职原因
- 收集改进建议
- 解答疑问
- 确认后续事项

### 4.5 手续办理
- 签署离职文件
- 开具离职证明
- 社保公积金转移
- 工资结算

## 5. 工资结算

- 离职当月工资按实际出勤计算
- 离职后15日内发放
- 补偿金按法律规定计算

## 6. 附则

- 本制度由人事行政财务中心制定并解释
- 自发布之日起执行
