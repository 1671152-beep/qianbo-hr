# 招聘与入职流程制度

## 1. 目的

规范公司人员招聘和入职流程，确保招聘工作的有效性、合规性，帮助新员工快速融入公司。

## 2. 适用范围

适用于公司所有正式员工的招聘和入职管理。

## 3. 招聘流程

### 3.1 需求确认
- 人事扩编审批已完成
- 确认岗位JD和任职要求
- 确定薪酬范围
- 明确到岗时间

### 3.2 招聘实施
| 步骤 | 内容 | 责任人 |
|------|------|--------|
| 发布职位 | 在各招聘渠道发布职位信息 | 人事 |
| 简历筛选 | 初筛符合要求的简历 | 人事 |
| 电话面试 | 基础信息核实和初步沟通 | 人事 |
| 初试 | 专业能力面试 | 用人部门 |
| 复试 | 综合素质面试 | 中心总监 |
| 终试 | 高管面试（经理级以上） | 副总经理/总经理 |
| 背景调查 | 核实工作经历和学历 | 人事 |
| 录用审批 | 确定录用意向和薪酬 | 人事+用人部门 |
| 发放Offer | 发送录用通知书 | 人事 |

### 3.3 招聘渠道
- 内部推荐（优先）
- 招聘网站（BOSS直聘、智联等）
- 社交媒体
- 校园招聘
- 猎头（高管岗位）

## 4. 入职流程

### 4.1 入职前准备
- 确认入职日期
- 准备入职材料清单
- 安排工位
- 准备办公设备
- 开通系统账号

### 4.2 入职材料
| 材料 | 要求 |
|------|------|
| 身份证 | 原件及复印件 |
| 学历证书 | 原件及复印件 |
| 离职证明 | 上家公司开具 |
| 体检报告 | 近3个月内 |
| 照片 | 1寸证件照2张 |
| 银行卡 | 工资卡 |
| 其他 | 资格证书等 |

### 4.3 入职当天
| 时间 | 内容 |
|------|------|
| 9:00-9:30 | 入职登记，签署劳动合同 |
| 9:30-10:30 | 公司介绍，制度培训 |
| 10:30-11:30 | 部门介绍，工作交接 |
| 11:30-12:00 | 熟悉环境，领取办公用品 |
| 下午 | 开展工作，导师带教 |

### 4.4 试用期管理
- 试用期：3个月（合同期3年）
- 导师制：指定导师一对一指导
- 月度沟通：直属上级每月沟通反馈
- 转正评估：试用期结束前进行

## 5. 附则

- 本制度由人事行政财务中心制定并解释
- 自发布之日起执行
