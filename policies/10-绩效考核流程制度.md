# 绩效考核流程制度

## 1. 目的

建立科学的绩效管理体系，客观评价员工工作表现，促进员工成长，提升组织效能。

## 2. 适用范围

适用于公司全体员工（试用期员工参照执行）。

## 3. 考核周期

| 类型 | 周期 | 适用对象 |
|------|------|----------|
| 月度考核 | 每月 | 运营、销售等岗位 |
| 季度考核 | 每季度 | 全体 |
| 年度考核 | 每年 | 全体 |

## 4. 考核内容

### 4.1 KPI（关键绩效指标）- 70%
- 与岗位核心职责相关的量化指标
- 具体目标值在期初设定

### 4.2 行为评价（价值观/能力）- 20%
- 企业文化契合度
- 工作态度
- 团队协作
- 学习能力

### 4.3 重点工作/项目 - 10%
- 当期重点任务的完成情况

## 5. 考核流程

```
目标设定 → 过程跟踪 → 自评 → 上级评价 → 绩效面谈 → 结果确认
```

### 5.1 目标设定
- 考核周期初设定目标
- 上级与员工沟通确认
- 目标需符合SMART原则

### 5.2 过程跟踪
- 每月/季度进行进度回顾
- 及时调整目标或提供支持

### 5.3 评价打分
| 等级 | 分数 | 比例 | 说明 |
|------|------|------|------|
| S-卓越 | 95-100 | 5% | 远超目标 |
| A-优秀 | 85-94 | 20% | 超越目标 |
| B-良好 | 70-84 | 60% | 达成目标 |
| C-待改进 | 60-69 | 10% | 部分达成 |
| D-不合格 | <60 | 5% | 未达成 |

### 5.4 绩效面谈
- 反馈考核结果
- 分析优势与不足
- 制定改进计划
- 确认下期目标

## 6. 考核结果应用

| 应用 | 说明 |
|------|------|
| 绩效工资 | 与绩效等级挂钩 |
| 晋升调薪 | 作为重要参考依据 |
| 培训发展 | 针对性培训计划 |
| 岗位调整 | 连续C/D需改进或调岗 |
| 淘汰 | 连续2次D，解除合同 |

## 7. 附则

- 本制度由人事行政财务中心制定并解释
- 自发布之日起执行
