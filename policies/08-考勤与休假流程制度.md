# 考勤与休假流程制度

## 1. 目的

规范公司考勤管理和休假制度，维护正常的工作秩序，保障员工的合法权益。

## 2. 适用范围

适用于公司全体员工。

## 3. 工作时间

### 3.1 标准工时
- 工作日：周一至周五
- 工作时间：9:00-12:00，13:30-18:30
- 午休时间：12:00-13:30

### 3.2 弹性工时
- 核心工作时间：10:00-12:00，14:00-17:00
- 弹性范围：8:00-10:00到岗，17:00-19:00离岗
- 每日工作时长不少于8小时

### 3.3 直播岗位
- 根据直播排班执行
- 需提前一周提交排班表
- 调休需提前申请

## 4. 考勤管理

### 4.1 打卡要求
- 每日上下班打卡
- 外勤需提交外勤申请
- 忘记打卡可补卡（每月限3次）

### 4.2 迟到早退
| 情况 | 处理 |
|------|------|
| 迟到≤15分钟 | 每月3次内免扣 |
| 迟到15-30分钟 | 扣0.5小时工资 |
| 迟到30-60分钟 | 扣1小时工资 |
| 迟到>60分钟 | 按半天事假 |
| 早退 | 参照迟到标准 |

### 4.3 旷工
- 无故缺勤视为旷工
- 旷工1天扣3天工资
- 连续旷工3天或累计5天，解除劳动合同

## 5. 休假类型

### 5.1 法定节假日
按国家规定执行。

### 5.2 年假
| 工龄 | 年假天数 |
|------|----------|
| 1-10年 | 5天 |
| 10-20年 | 10天 |
| 20年以上 | 15天 |

### 5.3 病假
- 需提供医院证明
- 工资按当地最低标准的80%发放

### 5.4 事假
- 需提前申请
- 事假期间无薪

### 5.5 婚假
- 3天（法定）+ 10天（公司福利）
- 需在入职后领证

### 5.6 产假/陪产假
按国家规定执行。

### 5.7 丧假
- 直系亲属3天
- 非直系亲属1天

## 6. 请假流程

```
提交申请 → 直属上级审批 → 中心总监审批（3天以上） → 人事备案 → 休假
```

| 请假天数 | 审批人 |
|----------|--------|
| ≤1天 | 直属上级 |
| 2-3天 | 中心总监 |
| >3天 | 副总经理 |
| >7天 | 总经理 |

## 7. 附则

- 本制度由人事行政财务中心制定并解释
- 自发布之日起执行
