# 设备管理流程制度

## 1. 目的

规范公司固定资产及设备的采购、领用、使用、维护和报废等全生命周期管理，提高设备使用效率，保护公司资产安全。

## 2. 适用范围

适用于公司所有固定资产及办公设备，包括：
- 电子设备（电脑、手机、平板、相机等）
- 办公设备（打印机、投影仪、会议设备等）
- 网络设备（路由器、交换机、服务器等）
- 直播设备（摄像机、灯光、声卡、麦克风等）
- 办公家具
- 其他价值≥2000元的资产

## 3. 设备分类

### 3.1 按价值分类
| 类别 | 价值标准 | 管理要求 |
|------|----------|----------|
| A类-核心资产 | ≥10000元 | 专项登记，年度盘点，总经理审批 |
| B类-重要资产 | 5000-9999元 | 部门台账，半年盘点，总监审批 |
| C类-一般资产 | 2000-4999元 | 统一登记，季度盘点，经理审批 |

### 3.2 按使用性质分类
| 类型 | 说明 | 示例 |
|------|------|------|
| 个人使用 | 分配给个人专用 | 工作手机、笔记本电脑 |
| 公用设备 | 部门/公司共用 | 打印机、投影仪 |
| 项目设备 | 随项目调配 | 直播设备、拍摄器材 |
| 库存备用 | 备用/新设备 | 未分配的新设备 |

## 4. 设备采购

### 4.1 采购申请

**申请条件**：
- 新增人员入职
- 设备达到报废年限/损坏无法修复
- 新业务/项目需要
- 设备性能不满足工作需要

**申请流程**：
```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  提交采购  │ → │  资产核查  │ → │  审批流程  │ → │  采购执行  │ → │  验收入库  │
│  申请单   │    │          │    │          │    │          │    │          │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
```

**申请材料**：
- 《设备采购申请单》
- 设备技术参数需求
- 2-3家供应商报价
- 使用人及用途说明

### 4.2 审批权限
| 设备类别 | 部门负责人 | 中心总监 | 副总经理 | 总经理 |
|----------|------------|----------|----------|--------|
| C类（2000-4999元） | 审核 | 审批 | - | - |
| B类（5000-9999元） | 审核 | 审核 | 审批 | - |
| A类（≥10000元） | 审核 | 审核 | 审核 | 审批 |
| 批量采购（总价≥20000元） | 审核 | 审核 | 审核 | 审批 |

### 4.3 采购执行
- 审批通过后由行政统一采购
- 优先选择协议供应商
- 大额采购需比价3家以上
- 合同需法务/财务审核

### 4.4 验收入库
- 收货后24小时内验收
- 核对型号、配置、数量
- 检查外观及功能
- 入库登记，贴资产标签
- 发票移交财务

## 5. 设备领用

### 5.1 领用流程
```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  提交领用  │ → │  库存核查  │ → │  审批发放  │ → │  签署确认  │
│  申请    │    │          │    │          │    │          │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
```

### 5.2 领用要求
- 新员工入职可领用标配设备
- 旧设备故障可申请更换
- 领用需签署《设备领用单》
- 明确设备保管责任人

### 5.3 标配标准
| 岗位类型 | 标配设备 |
|----------|----------|
| 管理人员 | 笔记本电脑+手机 |
| 主播/助播 | 工作手机+声卡设备 |
| 拍摄/剪辑 | 高配电脑+专业显示器 |
| 运营人员 | 台式电脑/笔记本 |
| 行政/财务 | 台式电脑 |

## 6. 设备使用

### 6.1 使用规范
- 设备仅限工作使用，禁止私用
- 不得擅自拆卸、改装设备
- 妥善保管，防止丢失损坏
- 离职时必须归还

### 6.2 维护保养
- 定期清洁保养
- 软件及时更新
- 发现故障立即报修
- 禁止私自维修

### 6.3 借用管理
- 设备借用需填写《设备借用单》
- 借用期限一般不超过7天
- 到期需归还或续借
- 损坏照价赔偿

## 7. 设备维修

### 7.1 报修流程
```
故障发现 → 提交报修 → 故障评估 → 维修执行 → 验收确认 → 费用结算
```

### 7.2 维修方式
| 情况 | 处理方式 |
|------|----------|
| 保修期内 | 联系售后免费维修 |
| 保修期外 | 评估维修价值后决定 |
| 维修费用<设备价值30% | 安排维修 |
| 维修费用≥设备价值30% | 申请报废换新 |

### 7.3 维修费用
- ≤500元：部门负责人审批
- 500-2000元：中心总监审批
- >2000元：副总经理审批

## 8. 设备调拨

### 8.1 调拨情形
- 人员岗位变动
- 项目结束设备回收
- 部门间资源调配
- 闲置设备再利用

### 8.2 调拨流程
- 填写《设备调拨单》
- 双方部门负责人确认
- 行政中心备案
- 更新资产台账
- 实物交接签收

## 9. 设备报废

### 9.1 报废条件
| 情况 | 说明 |
|------|------|
| 达到使用年限 | 电子设备5年，办公设备8年 |
| 技术淘汰 | 无法满足工作需求 |
| 严重损坏 | 维修成本过高或不值得维修 |
| 遗失 | 确认无法找回 |

### 9.2 报废流程
```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  提交报废  │ → │  技术鉴定  │ → │  审批确认  │ → │  资产处置  │ → │  账务处理  │
│  申请    │    │          │    │          │    │          │    │          │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
```

### 9.3 审批权限
| 设备类别 | 中心总监 | 副总经理 | 总经理 |
|----------|----------|----------|--------|
| C类 | 审批 | - | - |
| B类 | 审核 | 审批 | - |
| A类 | 审核 | 审核 | 审批 |

### 9.4 资产处置
- 有残值的资产可出售
- 涉密设备需专业销毁
- 环保设备按环保要求处理
- 处置收入上缴财务

## 10. 盘点管理

### 10.1 盘点周期
| 类别 | 盘点频率 |
|------|----------|
| A类资产 | 每半年 |
| B类资产 | 每季度 |
| C类资产 | 每季度 |
| 全部资产 | 每年年终 |

### 10.2 盘点流程
- 行政中心制定盘点计划
- 各部门配合实物盘点
- 核对账实一致性
- 盘盈盘亏分析处理
- 更新资产台账

## 11. 责任与赔偿

### 11.1 责任划分
- 领用人：日常使用保管责任
- 部门负责人：部门资产管理责任
- 行政中心：全公司资产管理责任

### 11.2 赔偿标准
| 情况 | 赔偿标准 |
|------|----------|
| 人为损坏 | 维修费用全额或折旧后价值的50% |
| 丢失 | 折旧后价值 |
| 私自变卖 | 原价赔偿，严重者追究法律责任 |
| 违规使用 | 视情节轻重处罚 |

### 11.3 折旧计算
```
年折旧额 = 资产原值 × (1 - 残值率5%) ÷ 使用年限
月折旧额 = 年折旧额 ÷ 12
```

## 12. 附则

- 本制度由人事行政财务中心制定并解释
- 自发布之日起执行
- 每季度进行制度执行情况检查
