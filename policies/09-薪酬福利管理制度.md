# 薪酬福利管理制度

## 1. 目的

建立科学合理的薪酬福利体系，吸引和留住优秀人才，激励员工创造更大价值。

## 2. 适用范围

适用于公司全体正式员工。

## 3. 薪酬结构

### 3.1 薪酬组成
```
总薪酬 = 基本工资 + 绩效工资 + 奖金 + 补贴 + 福利
```

### 3.2 基本工资
- 根据岗位价值、个人能力、市场水平确定
- 按月固定发放
- 作为社保公积金缴纳基数

### 3.3 绩效工资
- 与个人绩效挂钩
- 月度/季度发放
- 占比：基层20%，中层30%，高层40%

### 3.4 奖金
| 类型 | 说明 |
|------|------|
| 年终奖 | 根据公司效益和个人表现，1-3个月工资 |
| 项目奖 | 项目完成后的奖励 |
| 特别奖 | 突出贡献奖励 |

### 3.5 补贴
| 类型 | 标准 |
|------|------|
| 通讯补贴 | 100元/月 |
| 餐补 | 20元/工作日 |
| 交通补贴 | 200元/月 |
| 高温补贴 | 300元/月（6-9月） |

## 4. 薪酬等级

### 4.1 职级体系
| 职级 | 岗位示例 | 月薪范围 |
|------|----------|----------|
| P1 | 专员/助理 | 4K-6K |
| P2 | 高级专员 | 6K-8K |
| P3 | 主管 | 8K-12K |
| M1 | 经理 | 12K-18K |
| M2 | 高级经理 | 18K-25K |
| D1 | 总监 | 25K-35K |
| D2 | 副总经理 | 35K-50K |
| VP | 总经理 | 面议 |

## 5. 薪酬发放

### 5.1 发放时间
- 每月15日发放上月工资
- 遇节假日提前或顺延

### 5.2 发放方式
- 银行转账至工资卡
- 发放工资条

### 5.3 代扣代缴
- 个人所得税
- 个人社保公积金部分
- 其他依法代扣款项

## 6. 福利体系

### 6.1 法定福利
- 五险一金（养老、医疗、失业、工伤、生育+公积金）
- 法定节假日
- 带薪年假

### 6.2 公司福利
| 福利 | 说明 |
|------|------|
| 补充医疗 | 商业医疗保险 |
| 年度体检 | 每年一次 |
| 节日福利 | 春节、端午、中秋等 |
| 生日福利 | 生日礼金/礼物 |
| 团建经费 | 每人每年2000元 |
| 培训学习 | 公司出资的外部培训 |
| 图书补贴 | 每年500元购书额度 |

### 6.3 特殊福利
- 优秀员工旅游
- 股权激励（核心人员）
- 内部创业支持

## 7. 薪酬调整

### 7.1 调薪类型
| 类型 | 说明 | 频率 |
|------|------|------|
| 普调 | 全员调薪 | 每年1次 |
| 晋升调薪 | 职级晋升 | 随时 |
| 绩效调薪 | 优秀员工 | 每年2次 |
| 特殊调薪 | 市场调整/留人 | 随时 |

### 7.2 调薪流程
- 部门提名/人事评估
- 薪酬测算
- 逐级审批
- 沟通确认
- 生效执行

## 8. 附则

- 本制度由人事行政财务中心制定并解释
- 薪酬信息严格保密，禁止相互打听
- 自发布之日起执行
