# 费用申请流程制度

## 1. 目的

规范公司各项费用支出的事前申请流程，强化预算管控，确保资金使用的计划性和合规性。

## 2. 适用范围

适用于预算内的各类费用支出申请，包括但不限于：
- 市场推广费用
- 采购支出
- 项目支出
- 培训费用
- 设备购置
- 软件服务订阅
- 其他预算内支出

## 3. 费用申请分类

### 3.1 按性质分类
| 类别 | 说明 | 典型场景 |
|------|------|----------|
| 运营费用 | 日常经营所需 | 投流、账号费用、网电费等 |
| 采购费用 | 物资/服务采购 | 设备、软件、办公用品 |
| 项目费用 | 特定项目支出 | 拍摄、活动、制作 |
| 人力费用 | 人员相关支出 | 招聘、培训、团建 |

### 3.2 按金额分类
| 级别 | 金额范围 | 审批层级 |
|------|----------|----------|
| 小额 | ≤1000元 | 部门负责人 |
| 一般 | 1001-5000元 | 中心总监 |
| 大额 | 5001-20000元 | 副总经理 |
| 重大 | >20000元 | 总经理 |

## 4. 申请流程

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  填写费用  │ → │  预算核对  │ → │  逐级审批  │ → │  财务备案  │ → │  执行支出  │ → │  报销核销  │
│  申请单   │    │   确认    │    │          │    │          │    │          │    │          │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
```

### 4.1 详细步骤

**第一步：填写费用申请单**
- 登录HR系统 → 费用申请模块
- 选择费用类型和归属中心/部门
- 填写申请信息：
  - 费用名称及用途说明
  - 预算科目（系统自动关联）
  - 申请金额（含税/不含税）
  - 供应商信息（如有）
  - 期望执行时间
  - 预期效果/产出（投流等需填写）

**第二步：预算核对**
- 系统自动校验预算余额
- 预算充足：进入审批流程
- 预算不足：提示调整或申请追加预算

**第三步：逐级审批**
- 按金额级别自动流转审批人
- 审批人可：批准/驳回/转办/加签
- 审批意见需明确具体

**第四步：财务备案**
- 审批通过后财务锁定预算
- 生成申请编号
- 推送执行通知

**第五步：执行支出**
- 凭审批通过的申请单执行
- 优先使用对公转账
- 保留完整支付凭证

**第六步：报销核销**
- 费用发生后7天内提交报销
- 关联原费用申请单
- 实际金额与申请差额需说明

## 6. 特殊费用申请要求

### 6.1 投流费用（账号费用/投流费）
- 需提交投流计划表
- 明确投放平台、目标受众、预期ROI
- 单次超过10000元需附详细方案

### 6.2 软件服务订阅
- 需说明使用人数、功能需求
- 提供2-3家供应商比价
- 年费超过5000元需副总经理审批

### 6.3 设备采购
- 填写《设备采购申请单》
- 说明使用人、使用期限
- 提供技术参数和报价单

### 6.4 培训费用
- 提供培训课程大纲
- 说明参与人员及预期收益
- 外部培训需提前15天申请

## 7. 审批时限

| 审批环节 | 时限要求 | 超时处理 |
|----------|----------|----------|
| 直属上级 | 24小时 | 自动升级 |
| 中心总监 | 48小时 | 发送催办通知 |
| 副总经理 | 72小时 | 发送催办通知 |
| 总经理 | 72小时 | 发送催办通知 |

## 8. 变更与取消

- **申请变更**：未执行前可修改，需重新审批
- **金额调整**：超原申请20%需重新申请
- **申请取消**：审批通过后未执行可取消，释放预算
- **超期失效**：审批通过后30天内未执行自动失效

## 9. 监督与考核

- 财务每月汇总费用执行情况
- 超预算部门暂停新增申请
- 预算执行率纳入中心考核
- 违规申请记入诚信档案

## 10. 附则

- 本制度由人事行政财务中心制定并解释
- 紧急情况下可先执行后补申请（限2000元内，24小时内补齐）
- 自发布之日起执行
