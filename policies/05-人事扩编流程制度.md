# 人事扩编流程制度

## 1. 目的

规范公司人员编制管理，科学合理地控制人力成本，确保人员扩充符合公司战略发展和业务需要。

## 2. 适用范围

适用于公司各部门、各中心因业务发展需要增加人员编制的申请、审批和实施。

## 3. 扩编原则

### 3.1 基本原则
- **业务导向**：以业务需求为依据，不养闲人
- **效率优先**：先内部调配，后外部招聘
- **预算控制**：扩编必须在预算范围内
- **结构优化**：注重人才结构优化，提升团队能力

### 3.2 禁止扩编情形
- 编制已满且业务无实质性增长
- 可用外包/兼职替代全职岗位
- 可通过流程优化/工具提效解决
- 预算不足且无追加来源

## 4. 编制管理

### 4.1 编制体系
| 中心 | 现有编制 | 在岗人数 | 缺编 |
|------|----------|----------|------|
| 基地管理中心 | 10 | 10 | 0 |
| 本地生活运营中心 | 6 | 6 | 0 |
| 人事行政财务中心 | 3 | 3 | 0 |
| 商务中心 | 2 | 2 | 0 |
| **合计** | **23** | **21** | **2** |

### 4.2 编制调整权限
| 调整类型 | 审批权限 |
|----------|----------|
| 中心内部岗位调整 | 中心总监 |
| 跨中心人员调配 | 副总经理 |
| 增加编制（≤2人） | 副总经理 |
| 增加编制（>2人） | 总经理 |
| 组织架构调整 | 总经理 |

## 5. 扩编申请流程

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│  提交扩编  │ → │  编制评估  │ → │  预算审核  │ → │  逐级审批  │ → │  招聘实施  │ → │  到岗确认  │
│  申请表   │    │          │    │          │    │          │    │          │    │          │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
```

### 5.1 申请条件
- 业务增长超过20%
- 现有人员连续3个月超负荷工作
- 新业务/新项目启动
- 关键岗位人员流失需替补

### 5.2 申请材料
- 《人事扩编申请表》
- 扩编必要性说明
- 岗位说明书（JD）
- 人力成本预算
- 业务增长数据支撑
- 招聘方案

### 5.3 详细步骤

**第一步：需求提出**
- 部门负责人评估业务需求
- 与中心总监初步沟通
- 确认无法内部调配解决

**第二步：填写申请**
- 登录HR系统 → 人事扩编模块
- 填写扩编信息：
  - 岗位名称及层级
  - 招聘人数
  - 期望到岗时间
  - 薪酬预算范围
  - 岗位职责与任职要求
  - 扩编理由

**第三步：编制评估**
- 人事行政中心核查编制情况
- 评估内部调配可能性
- 出具编制评估意见

**第四步：预算审核**
- 财务核算人力成本
- 确认预算来源
- 超预算需申请追加

**第五步：逐级审批**
| 扩编人数 | 中心总监 | 副总经理 | 总经理 |
|----------|----------|----------|--------|
| 1-2人 | 审核 | 审批 | - |
| 3-5人 | 审核 | 审核 | 审批 |
| >5人 | 审核 | 审核 | 审批+董事会 |

**第六步：招聘实施**
- 审批通过后启动招聘
- 人事行政中心统一组织
- 用人部门参与面试
- 优先内部推荐

**第七步：到岗确认**
- 新员工办理入职
- 更新编制台账
- 归档扩编资料

## 6. 预算管理

### 6.1 人力成本构成
| 项目 | 计算基数 | 说明 |
|------|----------|------|
| 基本工资 | 月薪标准 | 根据职级确定 |
| 绩效奖金 | 基本工资×系数 | 季度/年度发放 |
| 社保公积金 | 基本工资×比例 | 公司承担部分 |
| 其他福利 | 固定值 | 餐补、通讯补等 |

### 6.2 月度人力成本预算（已批准）
| 中心 | 预算金额 | 备注 |
|------|----------|------|
| 基地管理中心 | ¥42,500 | 10人 |
| 本地生活运营中心 | ¥34,250 | 6人 |
| 人事行政财务中心 | 待核定 | 3人 |
| 商务中心 | 待核定 | 2人 |

### 6.3 扩编成本测算
扩编申请需测算年度新增成本：
```
年度新增成本 = (月薪标准 × 12 + 年度奖金 + 年度社保公积金 + 年度福利) × 招聘人数
```

## 7. 招聘实施

### 7.1 招聘渠道
| 渠道 | 适用岗位 | 优先级 |
|------|----------|--------|
| 内部推荐 | 全部 | ★★★★★ |
| 招聘网站 | 通用岗位 | ★★★★ |
| 猎头 | 高管/稀缺岗位 | ★★★ |
| 校园招聘 | 管培生/应届生 | ★★★ |
| 外包合作 | 临时/项目制 | ★★ |

### 7.2 招聘时限
| 岗位类型 | 招聘周期 |
|----------|----------|
| 普通岗位 | 30天内 |
| 专业岗位 | 45天内 |
| 管理岗位 | 60天内 |
| 紧急需求 | 协商确定 |

### 7.3 内推奖励
| 成功入职岗位 | 推荐奖励 |
|--------------|----------|
| 普通员工 | 500元 |
| 专业/技术岗 | 1000元 |
| 经理级 | 2000元 |
| 总监级 | 5000元 |

## 8. 特殊情况处理

### 8.1 紧急扩编
- 因突发业务需求需紧急扩编
- 可先口头报批，48小时内补单
- 但预算仍需事前确认

### 8.2 编制冻结
- 以下情况冻结新增编制：
  - 季度业绩未达标
  - 人力成本超预算
  - 组织架构调整期
  - 公司战略调整期

### 8.3 编制缩减
- 业务收缩需缩减编制
- 优先自然减员（不替补离职人员）
- 必要时协商解除劳动合同

## 9. 监督考核

### 9.1 用人部门责任
- 确保扩编必要性真实
- 控制招聘成本
- 新员工培养与留存
- 扩编后业绩达成

### 9.2 考核指标
| 指标 | 说明 |
|------|------|
| 招聘达成率 | 实际到岗/计划招聘 |
| 试用期通过率 | 转正人数/入职人数 |
| 人效比 | 业绩产出/人力成本 |
| 员工留存率 | 工作满1年员工比例 |

## 10. 附则

- 本制度由人事行政财务中心制定并解释
- 自发布之日起执行
- 每季度评估编制使用情况
