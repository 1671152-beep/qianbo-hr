### 7.2 盈亏平衡分析

```
固定成本 = 人工费用 + 办公费用 = ¥147,050
变动成本率 = 公务活动费 + 其他费用 / 销售收入 = 65.8%

盈亏平衡点 = 固定成本 / (1 - 变动成本率)
           = ¥147,050 / (1 - 0.658)
           = ¥429,971 (月度)

当前预算收入 = ¥319,500
缺口 = ¥110,471 (需增加34.6%)
```
