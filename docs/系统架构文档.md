# OpenClaw HR 系统架构文档

## 1. 系统概述

**系统名称**：OpenClaw HR  
**服务对象**：千播公司（21人，4大中心）  
**核心目标**：制度流程数字化、预算成本可视化、人事管理自动化

## 3. 功能模块

### 3.1 组织架构管理
- 公司/部门/岗位管理
- 人员档案管理
- 汇报关系图
- 编制管理

### 3.2 预算成本管理
- 年度预算编制
- 月度预算分解
- 预算执行监控
- 成本分析报表
- 预警提醒

### 3.3 流程审批中心
- 费用报销审批
- 费用申请审批
- 出差审批
- 人事扩编审批
- 采购/设备审批
- 自定义流程

### 3.4 考勤薪酬管理
- 考勤打卡
- 请假/加班管理
- 薪酬计算
- 社保公积金
- 工资条发放

### 3.5 资产管理
- 资产台账
- 采购/领用/归还
- 维修/报废
- 资产盘点

### 3.6 招聘入职
- 招聘需求管理
- 简历管理
- 面试安排
- 入职办理
- 试用期管理

### 3.7 绩效考核
- 目标设定
- 绩效评价
- 绩效面谈
- 结果应用

### 3.8 培训发展
- 培训计划
- 课程管理
- 学习记录
- 效果评估

## 4. 数据模型

### 4.1 核心实体

```
公司(Company)
├── 部门(Department)
│   ├── 岗位(Position)
│   │   └── 员工(Employee)
│   └── 预算科目(BudgetItem)
│       └── 预算明细(BudgetDetail)
├── 流程定义(ProcessDef)
│   └── 流程实例(ProcessInst)
├── 资产(Asset)
└── 制度(Policy)
```

### 4.2 预算模型

```
预算年度(BudgetYear)
├── 预算月份(BudgetMonth)
│   ├── 中心预算(CenterBudget)
│   │   ├── 科目预算(ItemBudget)
│   │   │   └── 预算执行(BudgetActual)
```

## 5. 审批流程矩阵

| 流程类型 | 申请人 | <1000 | 1000-5000 | 5000-20000 | >20000 |
|----------|--------|--------|-----------|------------|---------|
| 费用报销 | 员工 | 直属上级 | 中心总监 | 副总经理 | 总经理 |
| 费用申请 | 员工 | - | 中心总监 | 副总经理 | 总经理 |
| 出差申请 | 员工 | - | 中心总监 | 副总经理 | - |
| 人事扩编 | 总监 | - | 副总经理 | 总经理 | 总经理 |
| 设备采购 | 员工 | - | 中心总监 | 副总经理 | 总经理 |

## 6. 技术栈

| 层级 | 技术选型 |
|------|----------|
| 前端 | Vue3 + Element Plus |
| 后端 | Node.js / Python FastAPI |
| 数据库 | MySQL 8.0 + Redis |
| 文件存储 | MinIO |
| 消息队列 | RabbitMQ |
| 定时任务 | APScheduler |
| 部署 | Docker + Docker Compose |
