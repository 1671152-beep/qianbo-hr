## 📤 导入飞书文档的两种方式

### 方式一：直接创建（推荐）

1. 打开飞书 → 云文档 → 新建文档
2. 复制 `.md` 文件内容
3. 粘贴到飞书文档
4. 飞书会自动识别 Markdown 格式

### 方式二：批量导入

1. 将所有 `.md` 文件压缩为 `policies.zip`
2. 使用飞书开放平台 API 批量导入
3. 或联系飞书管理员批量创建

## 🎯 飞书集成建议

### 1. 制度查阅
- 将制度知识库链接放在全员群公告
- 在新员工入职指南中引用

### 2. 流程审批
可在飞书审批中直接引用制度条款：
- 报销审批 → 引用《报销流程制度》
- 费用申请 → 引用《费用申请流程制度》
- 出差申请 → 引用《出差流程制度》

### 3. 智能问答
使用飞书智能伙伴/机器人：
- 员工@机器人询问"报销标准"
- 机器人自动回复相关制度内容

## 📊 预算Excel模板使用

### 本地使用
1. 打开 `src/excel-generator.html`
2. 在浏览器中调整预算数据
3. 点击"生成Excel模板"
4. 下载的Excel包含公式，可继续编辑

### 飞书多维表格
可将预算数据导入飞书多维表格：
1. 导出CSV格式：`budget/预算明细表.csv`
2. 飞书多维表格 → 导入数据
3. 设置公式和视图

## 🔗 WEB系统访问

### 本地启动
```bash
cd /root/.openclaw/workspace/openclaw-hr/src
# 方式1：直接打开
open index.html

# 方式2：使用Python简易服务器
python3 -m http.server 8080
# 访问 http://localhost:8080
```

### 部署到服务器
可将 `src/` 目录部署到：
- Nginx/Apache 服务器
- GitHub Pages
- 阿里云OSS/腾讯云COS
